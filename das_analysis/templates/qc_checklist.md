# 中国石油大学 PSD 分析法 QA 清单

## 实验记录

- [ ] 图片内容已整理为 Excel。
- [ ] 两组实验已分开或用“实验组”字段清楚区分。
- [ ] 日期、实验编号、起止时间、流量、工况完整。
- [ ] 三台设备的点位范围完整。
- [ ] 脉宽和采样率已记录。
- [ ] 推定信息已明确标记。
- [ ] 用户已人工确认实验记录表。

## 数据覆盖

- [ ] 每台设备的数据目录已确认。
- [ ] 每条实验记录都已检查原始数据时间覆盖。
- [ ] 缺数据的设备/实验已记录原因。
- [ ] 点位范围检查使用的是实验时间对应的数据文件。

## 绘图

- [ ] 相位热力图绘制全部点位空间。
- [ ] 相位热力图色条固定为 -0.3 到 0.3。
- [ ] PSD 频带能量图只绘制设备关心点位范围。
- [ ] STFT 参数为 2 s 窗口、50% 重叠。
- [ ] 频带为 0~2、2~10、10~50、50~200 Hz。
- [ ] 频带能量图使用稳健自适应色条，或已注明固定色条。
- [ ] 文件名包含实验组、编号、时间、流量、设备和频带。

## PPT

- [ ] PPT 中包含数据覆盖概览。
- [ ] 每条实验记录按设备整理。
- [ ] 相位热力图和四个 PSD 频带能量图标注清楚。
- [ ] 渲染检查无文字/图片溢出。
- [ ] 至少抽查一条记录的全部图页。
