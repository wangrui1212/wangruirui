# 实验记录表字段模板

建议 Excel 至少包含以下字段。没有把握的内容填“待核对”，不要空着。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 日期 | 是 | 绝对日期，例如 2026-07-09 |
| 实验组 | 是 | 例如 第一组实验、第二组实验 |
| 实验编号 | 是 | 例如 1、2、A、B |
| 记录开始时间 | 是 | HH:MM 或 HH:MM:SS |
| 记录结束时间 | 是 | HH:MM 或 HH:MM:SS |
| 操作/工况 | 是 | 例如 调泵 |
| 流量(L/h) | 是 | 统一单位 L/h |
| silixia点位范围 | 是 | 例如 800~1130m |
| OV点位范围 | 是 | 例如 0~397m |
| 自研_2U点位范围 | 是 | 例如 320~378m |
| 脉宽 | 是 | 例如 50 ns |
| 采样率 | 是 | 例如 4 kHz |
| 备注 | 否 | 标明推定、缺失或人工修正来源 |

人工确认后才能进入批量绘图。
